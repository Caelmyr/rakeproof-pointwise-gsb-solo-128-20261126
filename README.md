# RakeProof · 斜光起伏校验台

将同一实体小样固定在同一机位，分别从左右低角度照明各拍一张。RakeProof 用左照为基准放置右照，比较两照的像素反差，辅助区分纹理、墨色和具有方向性的亮暗坡。适于台面小样核验，如纸面压线、工具刻痕或浅纹。可用「打开合成练习」即时进入可操作的两照核验卡。

## 启动

```sh
docker compose up --build -d --wait
```

在浏览器访问 http://127.0.0.1:19931/。结束时运行 `docker compose down`，两照原片与已用设置留在本项目命名卷。也可将 requirements.txt 安装到本机独立 Python 3.11 或 3.12 环境后运行 `./start.sh`，默认端口 8000。可设置 `PORT` 与 `RAKEPROOF_DATA` 指定端口与数据目录。

## 使用

1. 导入两张原照，或打开合成练习。用「两照交叠」及横、纵移量对齐右照。两照像素大小可不同。对齐为整像素平移，同一左照位置的右照坐标为左照坐标减去移量。
2. 用「框选量区」及「定位横切线」标记要核验的部分。可另外「框选平面」并启用亮度平衡，在平面共同覆盖区用可用点的左照灰度／右照灰度中位数，估算一个右照全局倍率。点击「应用读数设置」采纳为当前版。
3. 在影像、横切线或某个亮暗段上点击，或键入左照坐标，看两张原片实际读到的坐标与 RGB。叠图以暖色表示左照相对亮、蓝色表示右照相对亮。灰斜纹表示过暗或亮部剪切。横切线上无证位置断开。
4. 可保存量区校样 PNG、横切线 CSV、或两张原照与核验报告组成的 ZIP。可将任一原照送去图像准备，继续裁剪和调整；核验卡内的原坐标随时可重开。

左右来源以归一 EXIF 方向后的无损 RGB PNG 留存。支持不透明的单帧 PNG、JPEG、TIFF、BMP、WebP，每照最多 14 MiB、260 万像素，边长 24–2300 像素。量区的右、下边界不计入该区。平面平衡至少需要 24 个双方有效像素，倍率限于 0.4–2.5。双向都可复查且曝光正常时，算出 `100 × (左照灰度 − 平衡后右照灰度) / (左照灰度 + 平衡后右照灰度)`。反差是二维影像证据。材料反射、照明位置或相机相对摆动会影响结果。照片准备服务和试样卡各有数据目录，核验卡上限为 80 张。

「刻线与印痕」「薄印字与浅沟」「斜照亮斑和遮挡」都是程序合成的练习图案。有效后台源码行数使用 `python3 scripts/count_backend.py --project-root . --source-root rakeproof --source-root image_lab` 可复算。
